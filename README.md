## About the Project
### **Table Lamp** - It is a aesthetic table lamp with 140x skC6812RGBW matrix and Compatible with Compatible with [WLED framework](https://kno.wled.ge).
## Use case 
### Due to skC6812RGBW LED it can Provide Billions of color Combination light. And [WLED framework](https://kno.wled.ge) make this thing more Beginner friendly. Here are the common use cases :-
- it can be use as table lamp.
- it can be use as Studio lighting.
- it can be use as pixl display too just with the help of [WLED framework](https://kno.wled.ge).

## why i made this?
### i make this lamp to cover up my 3 Requirement. First as a Table lamp. Which have adjustable Light temperature control. and next as a Studio light. and also i use it as a pixel display at my desk.
